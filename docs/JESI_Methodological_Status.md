# JESI Methodological Status

## JAS Unified Economic Strength Index — Master Version 1.0

**Status:** Empirical validation completed for the current documented
production specification, with methodological limitations and coverage
constraints explicitly reported.

## 1. Production Specification

Study period:

2016–2023

Benchmark countries:

- Bangladesh
- India
- Vietnam
- Indonesia
- Malaysia

Production pillar weights:

- Growth: 0.20
- Productivity: 0.25
- Connectivity: 0.20
- Resilience: 0.20
- Strategic Autonomy: 0.15

Aggregation:

Weighted geometric aggregation.

## 2. Missing-Data Policy

The production calculation uses complete-case country-year observations.

The project does not:

- fabricate observations;
- silently impute missing values;
- interpolate missing values;
- automatically reweight countries because of missing observations;
- silently replace missing indicators with proxies.

## 3. Final Sample Coverage

The theoretical panel contains:

5 countries × 8 years = 40 country-years.

The current production complete-case sample contains:

34 country-years.

Therefore:

6 country-years are excluded because the required production
pillar information is incomplete.

Country-level coverage is unequal.

Bangladesh:

2 / 8 complete observations.

India:

8 / 8 complete observations.

Vietnam:

8 / 8 complete observations.

Indonesia:

8 / 8 complete observations.

Malaysia:

8 / 8 complete observations.

This unequal coverage is a methodological limitation and is explicitly
reported rather than hidden.

## 4. Balanced-Panel Sensitivity

A separate balanced-panel sensitivity analysis is conducted.

A country is considered balanced-panel eligible only when all eight
2016–2023 country-years contain complete G/P/C/R/A/JESI observations.

The balanced-panel analysis is a research-validation sensitivity test.

It does not replace the production result.

It does not remove Bangladesh from the baseline production calculation.

It does not introduce imputation.

It does not change pillar weights.

It does not change the aggregation method.

## 5. Research Validation Sequence

The locked research sequence is:

1. JESI Concept
2. Pillar validity
3. Indicator validity
4. Redundancy / correlation
5. Normalization sensitivity
6. Weight sensitivity
7. Aggregation sensitivity
8. Historical validation
9. Final methodological judgment

The research-validation layer is separate from the production methodology.

## 6. Interpretation

The current evidence should be interpreted as empirical evidence
within the documented research design.

It should not be interpreted as proof of:

- universal validity;
- causal relationships;
- predictive superiority;
- superiority over all alternative economic indices;
- official institutional endorsement.

Historical association does not by itself establish causality.

## 7. Current Methodological Statement

JESI is an empirically supported but not universally validated
multidimensional framework for assessing structural economic strength.

This statement applies specifically to the documented Master Version 1.0
production specification, benchmark countries, study period, data
availability, normalization rules, weighting scheme, aggregation method,
complete-case policy, and validation design.

## 8. Reproducibility

The repository is intended to support:

Retrieve → Process → Calculate → Reproduce → Evaluate

External data may be revised by their providers. Therefore exact
reproduction can depend on source-data version, retrieval date, provider
revisions, and licensing constraints.

## 9. Research Integrity Principle

The research-validation process must identify weaknesses rather than
hide them.

A methodological warning is not converted into a methodological failure
unless the evidence demonstrates an actual violation of the documented
research design.

Likewise, successful code execution does not by itself establish
scientific validity.
